# Drill

Home-screen flashcards (ML, system design, DSA, CS core, HR) in a thermal-camera look.
Tap a card to flip it, then mark **Again** or **Got it** (Leitner boxes: hotter = needs more work).
Tap the deck label on the front to switch decks. Open the app to add or import your own cards.

Every push to `main` builds the APK on GitHub Actions and publishes it to the **latest** release.
